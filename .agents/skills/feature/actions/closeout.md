# Closeout Action

1. Read `.agents/skills/closeout/SKILL.md` and prepare a concise handoff containing the verified
   checkout, branch, HEAD, diff, delivered scope, decisions, validation evidence, limitations,
   findings, pending goals, approval boundaries, and local material to preserve.
2. Keep implementation readiness distinct from full user-goal completion and live validation. If
   active goals remain, identify them as pending and leave the feature incomplete.
3. Continue in an existing closeout chat when one is already in use. Create a new chat only when the
   user explicitly authorized it, and provide the complete self-contained handoff.
4. Do not perform remote or destructive actions without current approval for the exact target and
   expected effect. Avoid requesting approval again when applicable current authorization is
   established.
