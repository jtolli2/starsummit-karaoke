## How It Connects

The guest route submits through the existing validated endpoints with a retained key and temporary credential. PocketBase authorizes the guest and atomically creates or replays the same request. A valid receipt confirms persistence; later HTTPS queue reads update separate feedback. Realtime remains a wake hint. Unknown outcomes retain the original tuple for safe retry; expired original credentials require host verification rather than identity replacement. Guests gain no direct collection access or tablet/playback controls.
